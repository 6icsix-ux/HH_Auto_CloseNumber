## 📋 ขั้นตอนการติดตั้ง

> ทำครั้งเดียวต่อเครื่อง ใช้ Google Chrome ปกติ

### 1️⃣ ดาวน์โหลดและติดตั้ง Tampermonkey
👉 [คลิกที่นี่เพื่อเปิด Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?pli=1)

<img width="1096" height="209" alt="image" src="https://github.com/user-attachments/assets/f616a16e-f3a1-451f-91db-4efe4efd53ca" />

### 2️⃣ เปิด **Allow User Scripts / อนุญาตสคริปต์ของผู้ใช้**
คัดลอกลิงก์ `chrome://extensions/` ไปวางในแถบที่อยู่ของ Chrome

2.1 คลิกที่ **Details / รายละเอียด** ในหน้าของ Tampermonkey

<img width="414" height="167" alt="image" src="https://github.com/user-attachments/assets/81c9a0ca-9b20-4120-98a2-44006f41d583" />

2.2 เปิดใช้งาน **Allow User Scripts / อนุญาตสคริปต์ของผู้ใช้**

<img width="678" height="85" alt="image" src="https://github.com/user-attachments/assets/a141106d-514f-465c-9b6a-141e424301a2" />

> ⚠️ **สำคัญ:** ถ้าไม่เปิดข้อนี้ สคริปต์จะติดตั้งได้แต่ไม่ทำงาน

### 3️⃣ เปิด **Allow access to file URLs / อนุญาตให้เข้าถึงไฟล์ URL**
3.1 หน้าเดิมจากหัวข้อ 2 เปิดใช้งาน **Allow access to file URLs / อนุญาตให้เข้าถึงไฟล์ URL**
